
# Intro to HTML

Last updated October 2023

HTML is a _markup_ language. It does not contain programming logic such as `if...else`.

A markup language in this context means that it helps you label your content in a way that gives it extra meaning and structure. Imagine you're writing using your favorite writing editor (for example, Google Docs, Apple Pages, Microsoft Office, etc.). You write the sentence _Benefits of doing sports every other day_. Then, you select this sentence and make it the title of the page. This is an analogy of how you markup a document.

HTML allows you to markup your document. For that, we'll learn many HTML elements with different meanings.

## HTML and CSS

In this course, we'll start by learning HTML followed by CSS. Then, we'll learn about the two concepts together as they are intertwined.

Suppose you compare HTML and CSS to the process of building a house. In that case, HTML represents the house structure, and CSS represents the finishing (aesthetics, styles, colors, etc.).

## Focus on semantics and accessibility

This course is different than many other courses as it heavily focuses on _semantics_ and _accessibility_. These two concepts will be introduced in the following two chapters. They are also part of most of the lessons of this course.

You will later see that browsers are pretty forgiving. You will almost always see a result on your screen. Many HTML courses teach you the quick and dirty way of doing things. This will be the opposite. So, please be patient. You will read lots of _'we will learn about this in later chapters_'. You will learn a lot (even if you've been writing HTML/CSS in the last few years)!

## A brief history of HTML

HTML was originally developed by [Tim Berners-Lee](https://en.wikipedia.org/wiki/Tim_Berners-Lee) while [working at CERN](https://home.cern/science/computing/birth-web). The main goal of HTML was the representation of documents that could be linked together.

## HTML element basic syntax

This chapter is meant to ease you into HTML. So, we won't be writing any HTML elements ourselves yet. In the next chapter, we will do so once we learn about the `h1` element.

Here's what an HTML element looks like:

```html
<h1>Benefits of doing sports every other day</h1>
```

In the code above, we have **one** `h1` element.  
This is made up of the `h1` _opening tag_ `<h1>` and the `h1` _closing tag_ `</h1>`.

We'll ask you to change a word inside the `<h1>...</h1>` tags in the following challenges.

We'll then re-explain the HTML element syntax in the next chapter.
